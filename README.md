# 🎉 WishLink — Personalized Wishing Website Builder

🔗 **Live Project:** [https://wishlink-7j0a.onrender.com/](https://wishlink-7j0a.onrender.com/)

**WishLink** is a creative web platform that allows users to create **personalized wishing websites** for special occasions such as **Birthdays, Anniversaries, Valentine’s Day, Weddings, and Festivals**. Users can customize templates and generate a unique, shareable link to send their wishes in a more engaging and memorable way.

This is **not just an idea or demo** — it is a **live, working product** with real users and real activity.

## ✨ Features

* 🎨 Multiple templates for different occasions
* 🔐 User authentication (Sign Up / Login)
* 📝 Custom name and message input
* 🖼️ Image customization – users can upload and personalize images
* 📊 Analytics integration to track user activity and usage
* 🧑‍💼 **Admin panel with separate pages** to monitor and manage all activities
* 🗂️ Admin access to users, links, and platform data handling
* 🔗 Permanent, shareable wish links
* 📱 Fully responsive design (mobile & desktop)
* ⚡ Smooth and fast user experience

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express.js
* **Templating Engine:** EJS & **EJS-Mate** (for layouts and reusable components)
* **Database:** MongoDB
* **Analytics:** Integrated usage & activity tracking
* **Hosting:** Render (onrender.com)

---

## 🧭 How It Works

1. Visit the WishLink website
2. Sign up or log in to your account
3. Choose a template based on the occasion
4. Customize the wish with name, images and message
5. Generate a unique wishing website link
6. Share the link with friends or family
